> **Web 课程设计项目仓库** ｜ **申报人**：蒋思睿 ｜ **学号**：`2024337621116` ｜ **班级**：24软件工程1班

## 📌 项目简介

**WanderSphere（漫游星球）** 是一款以柔和治愈系视觉为核心的 3D 全球智能旅行与地理风物探索 Web 平台。用户可轻点柔和微光的 3D 地球任意经纬度坐标，实时解码当地气象海拔与人文风物故事，并借助多模态 AI 生成当地特色地貌与代表建筑的立体微缩景观明信片，同时支持心愿坐标球面顺路串联与个人“足迹星球”点亮收藏。

## 🛠️ 计划核心技术栈

- **前端与三维交互**：Vue 3 · Vite · Three.js / Globe.gl · MapLibre GL JS · GSAP · Element Plus · Tailwind CSS · ECharts
- **后端与多模态编排**：Spring Boot 3 (JDK 17) · MyBatis-Plus · Spring Security + JWT · SSE 流式推送 · 文本与文生图大模型 API
- **数据存储与地理服务**：MySQL 8.0 · Redis 7.2 · Nominatim 逆地理编码 · Open-Meteo 气象高程接口
