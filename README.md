## ✨ 视觉定位与核心创意

告别传统地图冰冷杂乱的路网图标与暗黑刺眼的常规 WebGIS 大屏，**WanderSphere（漫游星球）** 以**暖白微光、莫兰迪柔彩地形与磨砂毛玻璃浮层**构建松弛治愈的探索氛围：

- **🌐 任意坐标轻点即达**：旋转柔和呼吸的 3D 地球，轻点全球任意一寸经纬度（城市、海岛、山谷、极地或大洋），镜头随 GSAP 物理阻尼平滑俯冲并流式展开当地天气、海拔、气候曲线与风物人文解说。
- **🎨 AI 绘就当地地貌与建筑微缩卡**：根据目标坐标真实地形、季节气象与乡土建筑形制，AI 自动绘出一张统一柔彩等轴测微缩景观（Isometric Diorama）立体插画卡；支持 3D 翻面写下旅途寄语与经纬度邮戳。
- **🪂 随心漫游与智能航线**：支持“盲盒跳伞”随机空降世界冷门角落、自然环境白噪音伴游，以及多心愿坐标球面顺路串联并点亮专属「足迹星球」。

## 🛠️ 核心技术栈

| 领域 | 技术选型 |
| :--- | :--- |
| **前端与 3D 视觉** | Vue 3.4+ · Vite 5 · Three.js / Globe.gl · MapLibre GL JS · GSAP · Element Plus · Tailwind CSS · ECharts 5 · Pinia |
| **后端业务网关** | Java 17 LTS · Spring Boot 3.3 · Spring Security 6 + JWT · MyBatis-Plus 3.5 · Knife4j |
| **数据与空间缓存** | MySQL 8.0 (InnoDB + JSON) · Redis 7.2 (GEO / GeoHash 网格缓存 / 分布式锁) |
| **地理与多模态 AI** | Nominatim 逆地理编码 · Open-Meteo 实时气象高程 · 大模型 SSE 流式百科 · AIGC 文生图（微缩景观） |
