## 🎯 项目简介

在高校《Web 程序设计》《软件工程》等实践类课程中，学生小组合作常面临**“盲目拉熟人导致技能失衡”“协作过程黑盒拖延”**以及**“期末有人划水搭便车（Free-Riding）、贡献度难以量化界定”**三大痛点。

**TeamPulse** 聚焦高校课程设计与竞赛组队场景，提供从**技能互补匹配成团 → AI 辅助拆解课程任务书 → 强制凭证留痕的拖拽看板 → 客观过程数据与匿名互评结合的贡献度核算 → 答辩级核验报告导出**的全流程闭环。

## 🛠️ 核心技术栈

| 领域 | 技术选型 |
| :--- | :--- |
| **前端技术栈** | Vue 3.4+ (Composition API) · Vite 5 · Pinia · Vue Router 4 · Element Plus · ECharts 5 · VueDraggablePlus · Axios |
| **后端技术栈** | Java 17 LTS · Spring Boot 3.3 · Spring Security 6 + JWT · MyBatis-Plus 3.5 · Knife4j (OpenAPI 3) |
| **数据与缓存** | MySQL 8.0 (InnoDB) · Redis 7.2 |
| **AI 能力集成** | OpenAI 兼容 REST/SSE 接口（DeepSeek / 通义千问 API，基于 JSON Schema 约束输出） |
